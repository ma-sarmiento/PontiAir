# PontiAir ✈️
# 🛫 Sistema de Gestión de Reservas Aéreas – Proyecto Universitario

**PontiAir** es un sistema básico de gestión de vuelos desarrollado como proyecto final para la asignatura **Introducción a la Programación** durante el semestre **2023-1** en la **Pontificia Universidad Javeriana**.  
Este proyecto fue desarrollado en **C++** y se enfoca en la implementación de estructuras de control, arreglos, funciones, modularidad, y menús interactivos para simular las operaciones fundamentales de una aerolínea.

---

## 📚 Descripción del proyecto

El objetivo principal del proyecto era construir un programa de consola que simulara un **sistema básico de reservas aéreas**, el cual permitiera:

- Registrar pasajeros con sus respectivos datos personales.
- Consultar vuelos disponibles según destino y horarios.
- Asignar vuelos a los pasajeros.
- Cancelar reservas si era necesario.
- Ver listados de pasajeros y sus vuelos asignados.
- Controlar el flujo del programa mediante un menú interactivo.

La lógica debía estar organizada utilizando **funciones** para cada una de las funcionalidades, promoviendo la reutilización de código y la estructuración lógica de tareas, conforme a los principios de **programación estructurada**.


## 🛠️ Funcionalidades implementadas

✔️ Registro de pasajeros  
✔️ Consulta de vuelos por destino  
✔️ Asignación de vuelo a pasajero  
✔️ Cancelación de reservas  
✔️ Visualización de listado de pasajeros con sus vuelos  
✔️ Menú principal con navegación por opciones  

## 🛠️ Estructura del código

El proyecto está organizado de forma modular en un único archivo `.cpp`, con funciones separadas para:

- **Validar entradas**
- **Registrar datos**
- **Mostrar resultados**
- **Controlar flujos con menú**

También se implementan estructuras como:

- Arreglos bidimensionales
- Funciones con parámetros y retorno
- Ciclos `for`, `while`, `do-while`
- Condicionales `if`, `else`, `switch`
